# Maintenance instructions

- Preserve the educational purpose and complete user journey.
- Do not silently change curated content meaning.
- Never claim official Ofsted status, endorsement, prediction or authoritative grading.
- Keep content and feedback rules separate from presentation.
- Run `npm test` and `npm run build` before finishing.
- Preserve static GitHub Pages compatibility and relative asset paths.
- Avoid unnecessary dependencies, remote services and persistent personal data.
- Maintain keyboard navigation, visible focus, reduced motion and responsive layouts.
