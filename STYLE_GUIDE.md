# Style guide

- Ink `#151915`; screen `#17211c`; paper `#e7dfc9`; institutional green `#385e46`; warning red `#8d322e`; record gold `#c5a35b`.
- Monospace display typography is paired with a readable slab-serif accent and system fallbacks.
- Panels use one-pixel borders, modest inset texture and strong separation.
- Primary controls are green; warnings use red; selected controls include a non-colour state and ARIA state.
- Portraits are original CSS illustrations. Do not import another game’s characters or assets.
- Motion is limited and stops under `prefers-reduced-motion`.
- Preserve visible focus, generous targets, semantic fieldsets, screen-reader labels, contrast and mobile layouts.
